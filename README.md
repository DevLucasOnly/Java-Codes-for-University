# Características de Linguagem ☕

Repositório dedicado aos códigos e projetos desenvolvidos durante a disciplina de **Características de Linguagem** do curso de Engenharia Elétrica da UERJ, com foco no estudo e aplicação da linguagem **Java**.

## 📚 Sobre o Repositório

O objetivo deste projeto é documentar o aprendizado das particularidades, sintaxe e paradigmas da linguagem Java. Aqui estão armazenados os exercícios práticos, demonstações de conceitos (como Orientação a Objetos) e trabalhos propostos ao longo do semestre.

## 🚀 Tecnologias e Ferramentas Utilizadas

*   **Linguagem:** Java
*   **IDEs:** Eclipse e Apache NetBeans
